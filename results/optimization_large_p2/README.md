# IndoBERT Large P2 – Hyperparameter Optimization

## Overview

This directory contains the evaluation results obtained from hyperparameter optimization experiments using the IndoBERT Large P2 model for Indonesian YouTube comment classification.

The experiments investigate the effect of different training configurations on classification performance. The results are used to identify an improved model configuration compared with the initial baseline.

## Files Description

| File | Description |
|---|---|
| `final_improved_metrics.csv` | Summary of evaluation metrics for the improved model configuration. |
| `final_improved_classification_report.csv` | Classification performance, including precision, recall, F1-score, and support for each class. |
| `final_improved_confusion_matrix.csv` | Numerical confusion matrix showing the actual and predicted class distributions. |

## Evaluation Metrics

The model is evaluated using the following metrics:

- Accuracy
- Precision
- Recall
- Macro-F1 Score

## Notes

These files represent the evaluation results of the hyperparameter optimization experiments. They are provided to support the comparison of model configurations and the analysis of classification performance.
